# 🕷️ 내 화면의 스파이디 (SpideyPet)

머리 크고 몸은 작은 꼬마 스파이디들이 바탕화면 위를 거미줄 타고 날아다니고, 모니터 가장자리를 기어다니는 Windows 데스크톱 펫이에요.

## 받기

이 저장소의 [`SpideyPet.exe`](SpideyPet.exe)를 받아 실행하면 돼요. 설치할 필요 없는 단일 실행 파일이에요. (Windows 64비트)

- 처음 실행할 때 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 눌러 주세요. (서명하지 않은 앱이라 뜨는 경고예요.)
- 컴퓨터를 켤 때 자동으로 실행돼요. 홈 화면에서 끌 수 있어요.
- exe를 다른 폴더로 옮겼다면 새 위치에서 한 번 실행해 주세요. 자동 실행 위치가 바뀌어요.
- 처음 켤 때는 파일을 푸느라 몇 초 걸릴 수 있어요.

## 조작법

| 조작 | 반응 |
| --- | --- |
| 한 번 클릭 | 점프 / 손 흔들기 / 거미줄 발사 |
| 두 번 클릭 | 연속 거미줄 스윙 |
| 드래그 | 잡아서 던지기 |
| 오른쪽 클릭 / 트레이 아이콘 | 메뉴 |

## 홈 화면에서 바꿀 수 있는 것

- 캐릭터 8종: 클래식, 마일스, 그웬, 심비오트, 아이언 스파이더, 미겔 오하라, 누아르, 스파이더 펑크
- 펫 크기, 함께 놀 친구 수, 활동량
- 활동 범위: 바닥·벽·천장 / 바닥·벽 / 바닥만
- 언어: 한국어 · English
- 컴퓨터를 켤 때 자동 실행

## 안내

개인이 만든 **비공식 팬메이드** 프로그램이에요. 스파이더맨 및 관련 캐릭터의 권리는 각 권리자에게 있어요. 상업적으로 사용하지 않아요.
